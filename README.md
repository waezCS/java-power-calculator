# Java Power Calculator

A simple Java console application that calculates a number raised to a user-defined power and allows the user to perform multiple calculations in one session.

## Features

- Accepts a number from the user
- Accepts a power/exponent from the user
- Calculates the result using `Math.pow()`
- Displays the result in the console
- Lets the user choose whether to perform another calculation
- Uses a `do-while` loop for repeated calculations

## Example

```text
Enter a number: 2
Enter the power: 5
2 power of 5 = 32
Do you want to calculate another number? (yes/no): yes

Enter a number: 3
Enter the power: 4
3 power of 4 = 81
Do you want to calculate another number? (yes/no): no

Program ended.
```

## Concepts Used

- Java
- `Scanner` for user input
- Variables
- `Math.pow()`
- Type casting
- `do-while` loops
- Conditional repetition

## What I Learned

This project helped me practice reading user input, working with mathematical methods, using loops, and designing a console program that can continue running until the user chooses to stop.

## How to Run

1. Make sure Java is installed.
2. Open the project in Eclipse, Visual Studio Code, or another Java IDE.
3. Run `Compute.java`.
4. Enter a number and a power when prompted.
5. Choose `yes` to calculate again or `no` to end the program.
